# Design sources and review material

Keep editable boards, reference assets, design briefs and useful visual comparisons
here. Runtime assets belong in `static/`; browser-check scripts and harnesses belong
in `scripts/visual-checks/`. Reserve the ignored root `output/` directory for
generated screenshots, logs and other disposable results.

- [Breadline brand review](breadline-brand-review/README.md): source artwork,
  editable boards, versioned comparisons and exported review bundles.
- Map-style studies: [first round](map-style-studies/hyper-directions/index.html)
  and [second round](map-style-studies/hyper-directions-v2/index.html).
- [Division icon brief](Division-Class-Icons-Imagegen-Brief.txt) and its
  [reference sheet](division-icons/icon-references.png).

Historical review material records the decisions at that time. Current runtime
brand treatments are maintained in `static/brands/breadline/`.
